    ComputerSystem

    output function

    • Mealy:g(input,state)
    • Moore:h(state)

    circuit Deley model

    2-1multiplexier with the output connected to A input,the selector is the clock signal.thus when clock is 0,it will select A and "remember" and when clock is 1,it will read in signal from B input.

    norS-norR Latch

    two NAND "cross-Coupling" when S and R all 1,the same as a circuit with two not gate thus remember. S=0 set.R=0 reset.

    Basic S-R latch

    the inverse of former one.

    clocked S-R latch

    the inputs will pass throuth a NAND with a clock signal.

    D latch

    no indetermninate because only one input A,which will branch into A and notA.memory only controled by clock. ### 问题： - 实践中输出连回输入是必需的，但是单个D锁存器会出现震荡问题，S-R主从锁存器的输出则是稳定的。

    主从触发器

    • 主处于透明态时，扑触发器锁定，时钟下降沿传递后主处于锁定态。
    • 1s cathing 由于S-R锁存器是mealy型的（即便不考虑时钟控制线），出现毛刺（Ainput从0到1再到0）时，输出不一定会恢复。而D锁存器在不考虑时钟控制线时是moore型的，于是出现毛刺会自动回复，没有一次性采样问题。

    Direct input

    • 直接输入（异步），作为初始化

    时序电路设计

    设计流程

    • obtain state diagram
    • assign binary code to each state
    • select the flip-flop type.derive the flip-flop input equations from the next-state entries.
    • derive output equations from the output entries in state table.
    • optimization (K-map) and tech mapping.

    rule for 状态编码分配

    • 输入相同次态相同，分配相邻编码
    • 同一个状态输入相邻时次态编码相邻
    • 相同输出的状态分配相邻编码
    • 出现最多OR起始状态的状态分配00

    例子：模3累加器

    register

    • mov,save,simple op
    • implecation collection of flip-flops
    • load=1 : accept new data load | clock --C input load=0 fixed 1(no edge); load=1 clock; problem:Gate delay(clock skew)
    • enable 2 multiplexer; one load new; one circle state now; backward:cost

    register transfers(+-|&<<>> mov)

    • microoperation:src,des;op;condition(control) -R0-R31 X0 X5X6(RISC-V); MEM[pc]:current instruction; pc:program counter;

    contrl expression:

    • CONTROL:OP
    • X K1：R1<=R1+R2非+1(substraction)
    • ~X K1:R1 <=R1+R2(K1:load;X;+-)
    • overflow:Cn-1异或Cn
    • Cn:进位

    register transfer structures

    • how regs connected
    • based on mux:ever reg bound with a reg R1(load)<=R2(s0,S1,S2) 交换可以并行; cost; Shared multiplexer(Bus)
    • 3-state bus(双向wire)

    shift reg

    • implementation: 1）串行，一个clock前进一个寄存器； 2）shift&~load&上一个;~shift&load&D;~shift&~load&现态 3)每个寄存器前面加一个4选择器

    counter

    • 所有状态遍历一遍,由时钟控制
    • PC:program counter
    • ripple counters;同步计数器
    • ripple counter:触发器的输入端接的自己，时钟接的上一个输出的非，在上一个触发器的下降沿变化;线少，功率低（高位反转次数少）；缺点：111->000:3gate delay, with some midstate such as 111->110->100->000.
