### 强归纳法
例子：n简单多边形可以n-1个三角化
> lemma：任何简单多边形都有内部对角线

良序性：任何非空子集有最小元
与两个归纳法等价

例子：
- 有限长度字符串（字典序）
- 带余除法q,r唯一性
- n有向完全图有n-环，必有3-环

### 递归定义
```
函数：f(0) f(n)->f(n+1)
```
例子：斐波那契数
> lame theorem:
欧几里得算法复杂度小于等于5*较小的数的十进制位数
